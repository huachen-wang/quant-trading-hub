# EAXAU V2 实现状态

更新时间：2026-08-22。

## 结论

技术需求的第一版架构已经形成，但 V2 代码尚未全部实现。当前完成的是“可以进入开发的需求与契约基线”，不是“新网站已经开发完成”。

## 已完成

- Vercel 相关项目已升级并验证 Node.js 24。
- 当前 `eaxau.com` V1 保持运行，TypeScript 与现有测试通过。
- 六核心策略、独立 EA 资料库、签约管理、自主分仓的产品边界已定义。
- 平台 × 策略 × 资金权重 × 风险预算的配方模型与校验规则已定义。
- EAXAU、Quant Data Core、Niubang Export Adapter 的职责与数据归属已定义。
- Quant Data Core Draft 0.1 接口、数据来源、新鲜度、演示标识和脱敏规则已定义。
- Claude UI 路由、视觉约束、交互状态、移动端和验收清单已定义。
- V2 明确使用功能开关和预览路由，不直接覆盖现网。

## 尚未实现

- `/v2-preview` 应用外壳与六策略首页。
- 六策略详情和后台图文内容块编辑器。
- 独立 EA 资料库在 V2 导航中的迁移与旧链接兼容。
- 本地 Demo Provider 与确定性测试数据。
- 自主分仓拖放/选择界面、权重编辑和校验引擎。
- 签约管理与自主分仓两类账户页。
- EAXAU V2 数据表、迁移、审计和功能开关。
- 独立 Quant Data Core 服务、缓存、SSE 和契约测试。
- Niubang Export Adapter、服务鉴权、用户授权映射与字段脱敏。
- 平台商业条款后台、规则版本和推荐规则引擎。
- 三视口视觉验收、端到端测试、灰度和正式切流。

## 开发前仍需确认

1. 六款核心策略的正式名称、唯一 ID 和各自数据源。
2. 首批平台名录、账户类型、返佣/成本来源和地区限制。
3. “签约管理”的最终中文名称与合同责任主体。
4. 自主分仓最多三个平台是否为固定产品规则。
5. EA 资料库正式导航名称使用“EA 商城”还是“EA 资料库”。
6. 第一版推荐方案由规则模板还是运营人工生成。

## 完成标准

只有以下条件全部满足，才可以说“所有技术需求已经做完”：

- 六策略、EA 资料库、详情、分仓和两种账户模式全部可操作。
- Demo、LIVE、STALE、OFFLINE 和权限状态都有完整表现。
- API 契约测试、单元测试、集成测试和端到端流程通过。
- 数据来源、金额、回撤、平台条款和更新时间可追溯。
- 牛帮现有接口与交易执行路径无行为变化。
- 桌面、平板和手机无溢出、遮挡、空白页和布局跳动。
- 预览环境完成业务验收，生产迁移和回滚方案经过演练。
