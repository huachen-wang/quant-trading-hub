# EAXAU V2 实现状态

更新时间：2026-08-23。

## 结论

EAXAU 仓库内的 V2 纵向链路已开发完成，并以根首页及新增 `v2` tRPC 命名空间实现。
原 EA 商城迁移到 `/market`，旧 API 与旧数据库结构没有改变。系统支持 `DEMO`、后台
`CUSTOM` 历史、Niubang/HTTP `LIVE` 与按时间交接的 `HYBRID`；是否可称为实盘由每个
策略的真实映射、同步状态和业务验收决定，不能由页面文案推断。

## 已完成

- `/` 六策略首页，并保留 `/v2-preview` 兼容入口；首屏直达六个席位，页面内完成“资金 × 风控 × 策略 × 平台 × 模式”选配。
- `/v2-preview/strategies/[id]` 高密度策略详情，包含指标、净值、账户快照、持仓、成交及可切换图文块。
- `/v2-preview/allocate` 券商模式高级选配器，支持 1 至 3 个平台、策略权重和风险预算，并继承首页选择。
- `/v2-preview/accounts` 与账户详情，覆盖资管模式和券商模式两种只读视图。
- 首页推荐接口会保留客户明确选择的策略与平台，并重新执行兼容性、门槛、集中度和回撤预算校验。
- `/v2-preview/ea-library` 独立 EA 资料库，复用旧目录、搜索、筛选、分页和咨询流程。
- `/admin/v2-content` 六策略内容后台，支持新建、编辑、排序、显隐、预览和删除。
- `/admin/v2-data` 数据后台，支持生成样本、编辑指标/净值和设置实盘接管线。
- 确定性 Demo Provider、HTTP Quant Data Provider、Niubang 公开策略只读适配器和严格的 Zod 数据契约。
- 策略卡桌面悬停速览、平台/策略选配检查器，以及详情页缩略图库和放大浏览。
- 平台、策略、资金权重、集中度、数据状态和回撤预算校验引擎。
- `DEMO`、`LIVE`、`STALE`、`OFFLINE`、加载、空数据、部分数据和错误表现。
- V2 单元测试、契约测试以及不修改 V1 顶层路由的兼容实现。
- 十张策略视觉图压缩为 960x540，降低首页图片传输和解码压力。
- `EAXAU_V2_ENABLED` 功能开关；关闭时只保留状态查询，其余 V2 调用被拒绝。
- 桌面策略拖放复用现有添加动作；重复、离线和不兼容策略由同一校验函数拒绝。
- 内容后台使用站内确认层、未保存保护、明确加载/错误状态和事务化整组排序。
- 非当前 V1 首页不再后台挂载，V2 首页实测只创建六张策略图片。
- 首页与账户卡片使用稳定回调；首屏三图与首屏以下图片采用不同加载优先级。

## 没有改动

- 现有 V1 tRPC procedure 名称、输入和输出。
- 现有支付、下载、登录、OAuth、邮件、短信和定时任务接口。
- 现有数据库迁移与表结构；V2 内容复用 `page_contents` 表。
- 牛帮交易执行、数据库和内部函数。
- EA 资料库原有目录、数据与详情能力；首页入口调整为 `/market`。

## 外部依赖，尚未接入

- 独立 Quant Data Core 的生产服务、缓存、SSE/推送及服务级监控。
- 牛帮客户私有账户的服务间鉴权、用户授权映射和敏感字段脱敏。
- 六款策略的真实账户 ID、正式净值、成交、持仓和证据资料。
- 三个平台的正式点差、返佣、出金、地区限制、合同和责任主体。
- 真实数据环境的端到端联调、故障演练、灰度切流和生产验收。

这些工作不能用演示数字代替。未配置 Provider 时系统固定使用 `DEMO`；配置 Niubang
映射后只读取现有公开 `signal.detail`，未映射席位仍是 `DEMO`，同步失败显示 `OFFLINE`。
HTTP Provider 校验所有响应，失败会明确报错，不会伪装成实时数据。

## 发布门槛

1. 本仓库类型检查、lint、自动测试、后端构建、Web 导出和静态验证全部通过；准确数量以根目录 `DEPLOYMENT_AUDIT.md` 为准。
2. 桌面 1440px、平板 1024px、手机 390px 无横向溢出、遮挡或空白页。
3. 生产环境设置 Node.js 24、数据库、鉴权密钥和 `EAXAU_V2_ENABLED=true`。
4. 接真实数据时设置 Quant Data Core URL/Key，并逐项核验来源和更新时间。
5. 业务方完成六策略、平台条款、风险文案与合同责任主体审核。
6. 根首页已切换为六策略体验；发布后同时抽查 `/market` 与支付、登录、下载旧链路。

最新一次自动化和视觉验证结果记录在仓库根目录 `DEPLOYMENT_AUDIT.md`。
